## Objetivo
Rediseñar el prototipo para que sea la versión final: experiencia fluida, limpia y moderna, mobile-first,
con todo el contenido del sitio original y un flujo de reserva por WhatsApp claro.

## Alcance
- Archivos a crear/modificar: `src/**` (App, componentes por sección, hooks, lib/time.ts, data/services.ts, index.css),
  `index.html` (SEO/OG), `package-lock.json` (regenerado en Linux), `public/images/gemoterapia.webp` (recorte).
- Fuera de alcance: backend de reservas, pagos, páginas adicionales, cambios en el workflow de deploy.

## Criterios de aceptación
- [ ] `npx tsc -b` y `npm run build` sin errores.
- [ ] Todo el contenido real del sitio original presente (servicios, precios, horario, políticas, contacto, Instagram, Facebook); ningún dato inventado.
- [ ] Reserva: no deja avanzar sin servicio, fecha/hora y nombre+teléfono; solo ofrece jueves/viernes/sábado; horas compatibles con la duración; abre WhatsApp con el resumen correcto.
- [ ] Servicio pausado (terapias energéticas) no se puede reservar; ofrece consulta por WhatsApp.
- [ ] Sin scroll horizontal a 390 px; overlays (menú, panel de servicio, galería, reserva) cierran con Escape y bloquean el scroll de fondo.
- [ ] Estado abierto/cerrado y fechas calculados en hora de Chile.

## Verificación
```bash
npm ci
npx tsc -b
npm run build
```
