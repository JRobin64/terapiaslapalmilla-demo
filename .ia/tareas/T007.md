# T007 — Fuentes servidas desde el propio sitio

- Estado: pendiente
- Implementa: codex
- Revisa: agy
- Depende de: T006

## Objetivo
Eliminar la cadena de peticiones a Google Fonts (HTML → fonts.googleapis.com CSS → fonts.gstatic.com woff2), que es lo que
aún retrasa el LCP móvil simulado (4,1 s tras T006; el LCP observado sin limitación de red es 59 ms). Servir las mismas fuentes desde el sitio.

## Alcance
- Archivos a crear/modificar: `public/fonts/*.woff2` (nuevos), `public/fonts/OFL.txt` (licencia), `src/index.css` (`@font-face`), `index.html` (quitar Google Fonts, añadir `preload` de las fuentes críticas).
- Fuera de alcance: cambiar de familia tipográfica, pesos o estilos; dependencias npm.

## Criterios de aceptación
- [ ] Mismas familias y variantes que hoy: Cormorant Garamond 500, 600, 500 itálica, 600 itálica; Plus Jakarta Sans 400, 500, 600, 700. Solo subconjunto `latin` (incluye á é í ó ú ñ ü ¿ ¡ $). Si Plus Jakarta Sans es fuente variable en Google, puede usarse un único archivo con rango de pesos.
- [ ] Archivos `woff2` en `public/fonts/` descargados de Google Fonts (fonts.gstatic.com, las mismas URLs que sirve la hoja CSS actual con un User-Agent moderno) y la licencia SIL Open Font License incluida en `public/fonts/OFL.txt`.
- [ ] `@font-face` en `src/index.css` con `font-display: swap` y rutas relativas que funcionen con `base: './'` en GitHub Pages (subcarpeta `/terapiaslapalmilla-demo/`).
- [ ] `index.html` ya no referencia fonts.googleapis.com ni fonts.gstatic.com (quitar preconnect, preload y noscript de T002); añade `<link rel="preload" as="font" type="font/woff2" crossorigin>` solo para las 2 fuentes que usa la portada sobre el pliegue (Cormorant Garamond 500 normal y 500 itálica o la que use el `<h1>`; y Plus Jakarta Sans regular).
- [ ] Aspecto visual idéntico; `npx tsc -b` y `npm run build` sin errores; el prerender de T006 sigue funcionando.

## Verificación
```bash
npx tsc -b
npm run build
grep -c "fonts.googleapis" dist/index.html
```
(el último debe dar 0)
