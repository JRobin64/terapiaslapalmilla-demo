# T004 — Imágenes responsivas para celular

- Estado: revision
- Implementa: codex
- Revisa: agy
- Depende de: T002

## Objetivo
Servir imágenes del tamaño adecuado en celular (Lighthouse estima 760 KiB de ahorro; p. ej. `estero.webp` 285 KB mostrada pequeña).

## Alcance
- Archivos a crear/modificar: `scripts/imagenes.py` (nuevo), `public/images/*-640.webp` y `*-960.webp` (generados), un componente o utilidad nueva en `src/components/ui/` para `srcset`, y los componentes que muestran fotos: Intro, ServiceCard, ServiceDrawer, Stay, Gallery, BookingModal (miniaturas), Footer/Navbar (logo: solo width/height).
- Fuera de alcance: la imagen de la portada en Hero.tsx y su preload (los toca T002), cambios de diseño.

## Criterios de aceptación
- [ ] `scripts/imagenes.py` genera, con Pillow (`python3 scripts/imagenes.py`), variantes de 640 y 960 px de ancho en WebP (calidad ~78) para cada foto de `public/images/` excepto `logo.webp`, sin ampliar imágenes más pequeñas que el ancho objetivo (en ese caso no se genera la variante). Es idempotente.
- [ ] Las variantes generadas se incluyen en el repo (el deploy no ejecuta Python).
- [ ] Las `<img>` de fotos usan `srcset` con las variantes existentes + el original, y un `sizes` acorde al ancho real en cada sitio (tarjetas: ~100vw en móvil, 50vw en sm, 33vw en lg; galería según su grilla; miniaturas de la reserva 48–64 px → usar la de 640 como `src`).
- [ ] Las `<img>` del logo y de las fotos tienen `width` y `height` (proporción real) para evitar saltos de diseño.
- [ ] Aspecto visual sin cambios; `npx tsc -b` y `npm run build` sin errores.

## Verificación

npx tsc -b
npm run build
